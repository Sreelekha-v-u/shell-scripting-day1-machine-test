## Script Descriptions

1. **welcome.sh** – Displays welcome messages.
2. **student.sh** – Collects and displays student information.
3. **userinfo.sh** – Accepts the user's name and course and displays a welcome message.
4. **systeminfo.sh** – Displays the current user, home directory, and shell.
5. **report.sh** – Displays the current date and logged-in user using command substitution.
6. **Task 6 – Script Execution** – Checks file permissions, adds execute permission, and executes a script.
7. **automation.sh** – Generates a server report containing date and time, current user, system uptime, and disk usage.

## Purpose
This project demonstrates basic Linux shell scripting, variables, user input, command substitution, file permissions, and automation.
